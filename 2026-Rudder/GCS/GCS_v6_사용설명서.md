# RUDDER GCS v6 사용 설명서

`gcs_v6.py` (version6 펌웨어 전용) 사용법 정리. 안전 원칙과 코드 상세는 `2026-Rudder/version6/CHANGES.md`, `GPT_REVIEW_RESPONSE_0730.md` 참고.

## 1. 실행

```bash
pip install -r requirements.txt
python -m streamlit run gcs_v6.py
```

브라우저가 자동으로 열리지 않으면 터미널에 뜨는 `http://localhost:8501` 주소로 직접 접속.

## 2. 화면 구성

### 사이드바 — 연결
- **지상측 SiK 포트**: 드롭다운에서 지상국 SiK 라디오가 꽂힌 COM 포트 선택
- **연결** 버튼: 클릭 시 해당 포트로 시리얼 연결 시도. 상태 캡션이 `🟢 연결됨`으로 바뀌는지 확인
- 로그 파일명(`gcs_v6_YYYYMMDD_HHMMSS.csv`)과 패킷 크기(47 bytes)가 하단에 표시됨

### 모드 배지 (좌측 상단 큰 박스)
로켓이 실제로 보고하는 현재 모드를 색으로 표시:

| 모드 | 색 | 의미 |
|---|---|---|
| 대기 | 회색 | SAFE — 명령 대기만, 사출 로직 없음 |
| 준비 | 주황 | ARMED — 기준압 수집 완료, 발사감지 중 |
| 비행 | 파랑 | FLIGHT — 발사 감지됨, 주사출 검사 중 |
| 낙하 | 초록 | DESCENT — 사출 완료, 착륙 대기 |
| 착륙 | 보라 | LANDED — 회수 단계, SD 닫힘 |

그 아래 센서 상태점(●BMP ●IMU ●SD ●INA ●기준압)은 초록=정상, 빨강=이상. **기준압이 빨간색이면 고도 기반 발사감지·정점판정이 비활성화된 상태**(가속도 경로와 10초 백업 타이머는 계속 작동).

서보 전원 표시(ON/OFF)는 **MOSFET 신호(명령) 기준**이지, 실제 전류를 측정한 게 아님 — 참고용.

### 텔레메트리 수치
수신율 / 손실 누적 / 손상(CRC) / 총 수신 — 링크 품질 확인용. 수신율이 0으로 떨어지면 통신 두절 의심.

고도 / 전압 / **X가속도**(발사 감지축, 2026-07-30 실측 확인) / 명령 수신 / SD로그 상태(미장착·대기·기록중·종료) 표시.

### 🎛️ 모드 제어
버튼은 **현재 모드와 정확히 일치할 때만 활성화**됨(오작동 방지). 클릭 후 위 모드 배지가 바뀌는지로 실제 적용 여부 확인 — 배지는 로켓이 보고하는 실제 상태라 이게 안 바뀌면 명령이 안 들어간 것.

- **준비→대기 전환**: ARMED에서만 가능
- **대기→준비 전환**: SAFE에서만 가능, 클릭 시 로켓이 약 1초간 기준압 수집(블로킹)
- **준비→비행 강제진입**: ARMED에서만 가능. **5초 내 재확인 필요**, 확인 즉시 10초 보조사출 타이머 시작됨 — 되돌릴 수 없는 명령이니 신중히
- **낙하→착륙 강제전환**: DESCENT에서만 가능. 착륙은 자동판정 없음, 실제 회수 확인 후 이 버튼으로만 전환

### 🚨 비상 사출
3단계 안전장치:
1. **[비상 사출]** 클릭 → 5초 내 [실행 확인] 필요 (실수 클릭 방지)
2. 확인 시 0.3초 간격으로 **자동 재전송 시작** (링크 불안정 대비)
3. 로켓이 `eject_state=1`로 응답할 때까지 계속 재전송, **최대 30초** 후 자동 중단(무한 재전송 방지)

⚠️ "명령 실행됨" 표시는 **펌웨어가 사출 함수를 실행했다는 뜻이지, 실제 낙하산이 펼쳐졌다는 물리적 확인이 아님.**

대기(SAFE)·착륙(LANDED) 상태에서는 펌웨어가 이 명령을 거부하므로, 30초 타임아웃 메시지가 뜨는 게 정상입니다(오작동 아님).

### 타임라인 & 그래프
발사/사출/착륙 시각 자동 기록. 하단 그래프는 고도와 X축 가속도(발사 감지축) 추이 — 점선은 발사감지 임계값(+2g = 2000mg).

## 3. 재연결 / 재부팅 상황

- **GCS 재연결 시**: 이전 비행 데이터(모드, 그래프, 사출 상태)가 자동으로 초기화됨 — 화면이 "미수신" 상태로 잠깐 보이는 게 정상
- **로켓이 리셋됐을 때**: GCS가 장치 시간 역행을 감지해서 자동으로 새 비행으로 인식하고 초기화함 (토스트 알림 뜸)

## 4. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 포트 목록에 아무것도 안 뜸 | SiK 동글이 노트북에 꽂혀있는지, 드라이버 설치됐는지 |
| 연결 눌러도 "연결 실패" | 다른 프로그램(Arduino 시리얼 모니터 등)이 같은 포트 점유 중인지 |
| 연결됐는데 수신율 0 | 로켓 쪽 전원·SiK 확인. GCS는 지상 SiK와만 연결된 것이라 로켓이 꺼져있어도 "연결"은 됨 |
| 비상사출이 계속 거부됨(30초 타임아웃) | 현재 모드가 대기/착륙이면 정상 동작(펌웨어가 의도적으로 거부) |

## 5. 로그

세션마다 `logs/gcs_v6_YYYYMMDD_HHMMSS.csv`에 자동 저장. 원시 텔레메트리(가속도 3축, 자이로 3축, 압력, 전압/전류, 모드 등) 전부 기록되므로 실시간 화면에 안 보이는 값(Y/Z축 등)도 사후 확인 가능.
